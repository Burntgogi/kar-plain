왜 언어와 장르를 함께 나누는가
ASD-STE100은 영어의 통제 어휘와 작성 규칙을 갖춘 기술 문서용 체계다. 한국어에는 영어 승인 단어·품사·의미 규칙을 그대로 적용할 수 없다. 이번 영어 의견문도 표준명을 지정했다고 더 좋은 결과가 되지 않았다. 따라서 영어 절차와 기술 설명은 ASD-STE100을 작성 기준으로 삼고, 일반 영어 글과 한국어는 STE-inspired clarity로 자연스럽게 쓰는 C2를 채택한다. 어느 쪽이든 주장 강도, 전문용어, 논리 연결과 행동 단위는 보존한다. 표준을 작성 기준으로 사용하는 것과 준수를 전수 검증하는 것은 다르며 이 실험은 후자를 수행하지 않았다.

해석의 범위

A cache stores a result that the application has already computed. This lets the application avoid the same computation again.

In this example, the cache key identifies the stored result by the document ID and its version. If the document version changes, the cache does not have a result for that key. This is called a cache miss. It does not mean that the original document was deleted.

The cache can reduce response time for repeated requests for the same document version. It does not improve every request. A cache is not a backup.
