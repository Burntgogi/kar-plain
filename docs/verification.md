# 확인한 범위

2026년 10월 5일 한 스킬에서 한국어와 영어를 선택하도록 수정하고, 두 언어의 글·도해·웹·영상을 각각 제작했다. 같은 Codex 에이전트가 작성하고 검토했다.

| 대상 | 확인 내용 |
| --- | --- |
| 스킬 | 구조 검사 통과, 설치본과 작업본의 두 파일 일치, 영문 실행 본문 299단어, 명시적 호출 정책 유지 |
| 언어 선택 | 출력 언어 지정 → 알려진 언어 선호 → 현재 요청 언어 순서; 인용 원문의 언어 제외; 글·라벨·UI·자막·요청한 나레이션에 적용 |
| 글 | 한·영 소개 글 각각 작성, 의미·조건·부정·의무·가능성과 출처 대조 |
| 도해 | 두 SVG의 XML 파싱, 관계·방향·라벨과 렌더링 확인, 각각 Mermaid 원본 제공 |
| 웹 | 한·영 페이지의 네 모드 전환, 출력 언어 선택, 주제 수정과 빈 입력 처리 확인; 390×844 CSS 화면에서 가로 넘침 없음 |
| 영상 | 각각 H.264, 1280×720, 24fps, 1,440프레임, 60초; 전체 파일 디코딩, 브라우저 재생과 장면별 화면 확인 |
| README | 각 언어의 예시 연결, 상대 링크 31개·이미지 10개·목차 검사; 영문판의 예시는 outputs/en에 연결 |
| 개인정보 | 배포 대상 39개 파일, HTML 내부 자료와 ZIP 2개 검사; 개인 로컬 경로·연락처·인증정보 검사와 화면·메타데이터 검토 |
| 라이선스 | MIT 유지; 저작권자는 공개 계정명 Burntgogi, 배포 ZIP에도 LICENSE 포함 |

한국어 예시는 outputs에, 영어 예시는 outputs/en에 있다. 각각 독립 실행 가능한 HTML에 해당 언어의 도해, 영상과 다운로드 자료를 넣었다. 두 영상에는 해당 언어의 자막을 화면에 표시하고 별도 UTF-8 SRT도 제공한다. 음성 나레이션은 없다. 각각의 README GIF는 MP4의 18초부터 36초까지 추출한 18초 미리보기다. GIF는 720×405, 108프레임이다.

Chrome에서 한·영 웹의 버튼과 입력을 실제로 조작했다. 영어 UI에서 Korean을 선택하거나 한국어 UI에서 English를 선택하면 표시된 호출문의 출력 언어가 바뀌었다. 이 웹은 호출문을 만드는 설명 예시이며, 설명 생성은 Codex에서 실행한다. 두 웹의 오류·경고 로그에는 관련 오류가 없었다. 영어 모바일 카드의 가로 넘침을 수정하고 다시 확인했다.

개인정보 검사는 README, 스킬, 예시, 문서, 공개 스크립트와 ZIP을 대상으로 한다. HTML 내부 자료는 검사한 원본과 파일 해시가 일치한다. 설치본에는 스킬의 두 파일만 있다. 로컬 작업 경로가 들어 있는 work 폴더와 작업용 기록은 배포 대상에서 제외한다. Git 커밋에는 공개 계정명과 GitHub 비공개 이메일을 사용한다.

저장소는 [Burntgogi/kar-plain](https://github.com/Burntgogi/kar-plain)에 비공개로 게시했다. 최초 게시와 MIT 반영 때 GitHub에서 한·영 README, 이미지, 목차, 언어 전환과 파일 링크를 확인했다. HTML은 내려받아 브라우저에서 열며, GitHub의 MP4 파일 화면은 원본 다운로드 링크를 제공한다.

이 기록은 이번 예시의 파일 구조, 표시와 동작을 확인한 범위다. 독립 인간 평가, 다른 주제의 설명 품질 비교나 모든 환경의 호환성 시험은 수행하지 않았다. 언어 선택은 에이전트가 스킬 지침을 적용하는 방식이며 운영체제 언어를 자동으로 읽는 프로그램은 추가하지 않았다.
