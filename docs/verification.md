# 확인한 범위

## 초기 한·영 제작 예시 — 299단어 본문

2026년 10월 5일 한 스킬에서 한국어와 영어를 선택하도록 수정하고, 두 언어의 글·도해·웹·영상을 각각 제작했다. 같은 Codex 에이전트가 작성하고 검토했다.

| 대상 | 확인 내용 |
| --- | --- |
| 스킬 | 구조 검사 통과, 설치본과 작업본의 두 파일 일치, 영문 실행 본문 299단어, 명시적 호출 정책 유지 |
| 언어 선택 | 출력 언어 지정 → 알려진 언어 선호 → 현재 요청 언어 순서; 인용 원문의 언어 제외; 글·라벨·UI·자막·요청한 나레이션에 적용 |
| 글 | 한·영 소개 글 각각 작성, 의미·조건·부정·의무·가능성과 출처 대조 |
| 도해 | 두 SVG의 XML 파싱, 관계·방향·라벨과 렌더링 확인, 각각 Mermaid 원본 제공 |
| 웹 | 한·영 페이지의 네 모드 전환, 출력 언어 선택, 주제 수정과 빈 입력 처리 확인; 390×844 CSS 화면에서 가로 넘침 없음 |
| 영상 | 각각 H.264, 1280×720, 24fps, 1,440프레임, 60초; 전체 파일 디코딩, 브라우저 재생과 장면별 화면 확인 |
| README | 각 언어의 예시 연결, 상대 링크 31개·이미지 10개·목차 검사; 영문판의 예시는 outputs/en에 연결 |
| 개인정보 | 배포 대상 39개 파일, HTML 내부 자료와 ZIP 2개 검사; 개인 로컬 경로·연락처·인증정보 검사와 화면·메타데이터 검토 |
| 라이선스 | MIT 유지; 저작권자는 공개 계정명 Burntgogi, 배포 ZIP에도 LICENSE 포함 |

한국어 예시는 outputs에, 영어 예시는 outputs/en에 있다. 각각 독립 실행 가능한 HTML에 해당 언어의 도해, 영상과 다운로드 자료를 넣었다. 두 영상에는 해당 언어의 자막을 화면에 표시하고 별도 UTF-8 SRT도 제공한다. 음성 나레이션은 없다. 각각의 README GIF는 MP4의 18초부터 36초까지 추출한 18초 미리보기다. GIF는 720×405, 108프레임이다.

Chrome에서 한·영 웹의 버튼과 입력을 실제로 조작했다. 영어 UI에서 Korean을 선택하거나 한국어 UI에서 English를 선택하면 표시된 호출문의 출력 언어가 바뀌었다. 이 웹은 호출문을 만드는 설명 예시이며, 설명 생성은 Codex에서 실행한다. 두 웹의 오류·경고 로그에는 관련 오류가 없었다. 영어 모바일 카드의 가로 넘침을 수정하고 다시 확인했다.

개인정보 검사는 README, 스킬, 예시, 문서, 공개 스크립트와 ZIP을 대상으로 한다. HTML 내부 자료는 검사한 원본과 파일 해시가 일치한다. 설치본에는 스킬의 두 파일만 있다. 로컬 작업 경로가 들어 있는 work 폴더와 작업용 기록은 배포 대상에서 제외한다. Git 커밋에는 공개 계정명과 GitHub 비공개 이메일을 사용한다.

저장소는 [Burntgogi/kar-plain](https://github.com/Burntgogi/kar-plain)에 비공개로 게시했다. 수정본 게시 후 GitHub 영문 README의 영어 소개 글, 도해, 웹 화면과 영상 GIF가 모두 로드되는 것을 확인했다. 예시 링크는 영어 폴더로 연결됐고, 영어 소개 글과 MP4 파일 화면도 실제로 열어 확인했다. GitHub에서도 두 README를 390×844 화면으로 확인했으며 페이지 전체의 가로 넘침이 없었고 언어 전환이 작동했다. 저장소 소개에서도 한국어 기본값을 없앴다. HTML은 내려받아 브라우저에서 열며, GitHub의 MP4 파일 화면은 원본 다운로드 링크를 제공한다.

이 기록은 이번 예시의 파일 구조, 표시와 동작을 확인한 범위다. 독립 인간 평가, 다른 주제의 설명 품질 비교나 모든 환경의 호환성 시험은 수행하지 않았다. 언어 선택은 에이전트가 스킬 지침을 적용하는 방식이며 운영체제 언어를 자동으로 읽는 프로그램은 추가하지 않았다.

## 글 모드 수정과 A/B/C 비교

2026년 10월 5일 기존 A(STE-inspired clarity), B(ASD-STE100 직접 지시), 새 C를 같은 한·영 원문 8개로 비교했다. A/B 결과는 원본 해시와 일치하도록 보존했다. 첫 C에서는 영어 의견문의 주장 강도와 한국어 환불 예외 표현에 우려가 남아 한 차례 보강했다. 최종 C2는 영어 절차문·기술 설명에 ASD-STE100을 적용하고, 한국어와 일반 영어 글에는 STE-inspired clarity를 적용한다. 용어 풀이, 주장 강도, 논리 연결과 절차의 행동 분리를 함께 지시한다.

각 라운드의 24개 결과를 조건명이 없는 무작위 순서로 별도 에이전트 두 명에게 검토하게 했다. 하나는 228개 원문 사실을 대조했고, 다른 하나는 원문별 세 결과의 의미, 어휘 접근성, 담화 구조, 말투와 경제성을 비교했다. 서로 다른 결과는 A/B 16개, 첫 C 8개, 보강 C2 8개로 총 32개다. 기존 결과를 반복 생성하거나 검토 후 문구를 고치지 않았다.

최종 익명 언어학적 비교의 단독·공동 선호 횟수는 A 3개, B 2개, C2 6개다. 공동 선호를 각각 세므로 합계는 원문 수 8개를 넘을 수 있다. 이는 한 검토 에이전트의 텍스트 판단이며 독자 이해도나 통계적 우월성의 측정이 아니다. [전체 비교 기록](prose-comparison.txt)에는 실제 원문·출력·판정과 최종 선택 근거가 있다.

최종 실행 본문은 308단어이며 스킬은 두 파일 구조를 유지한다. 설치본과 작업본의 두 파일을 대조하고 구조 검사를 수행했다. README 배지는 현재 본문 크기를 표시한다. 기존 글·도해·웹·영상과 미리보기는 초기 299단어 지침으로 만든 자료로 표시하고 보존했다. 비교 원문은 직접 작성한 가상 사례다.

수정한 두 README의 상대 링크는 각각 33개, 이미지는 각각 10개이며 링크·SVG·본문 크기 검사에 통과했다. 배포 대상 40개 파일, HTML에 포함된 자료와 미디어 메타데이터를 다시 검사했고 개인정보 패턴이 발견되지 않았다. 저장소 ZIP의 40개 항목과 설치·예시 ZIP의 19개 항목은 검사한 작업본과 바이트 단위로 일치한다. 개인 작업 기록은 ZIP과 Git 게시 대상에서 제외했다.

이 실험은 각 조건·원문당 한 번 생성한 결과를 비교한다. A/B와 C의 실행 시점, 에이전트 맥락과 한국어 높임 표현을 모두 통제하지 않았다. 표준 사전의 단어·품사·의미를 전수 검증하지 않았으며, 사람의 독해 실험을 수행하지 않았다. 설치 구조와 한·영 언어 선택 정책, 글 이외의 모드는 유지했다.

## 듀얼 호스트 플러그인 이식

2026년 10월 7일 PR #1을 검토해 저장소를 Claude Code와 Codex가 함께 쓰는 플러그인 마켓플레이스 구조로 옮겼다. 스킬 본문은 그대로 두고 배치와 메타데이터만 바꿨다. 플러그인에는 `plugin.json`, `SKILL.md`, `agents/openai.yaml`만 있으며 hooks, MCP 서버, 에이전트, 실행 파일은 없다.

| 대상 | 확인 내용 |
| --- | --- |
| 구조 | 스킬 파일은 `plugins/kar-plain/skills/kar-plain` 한 곳에 둔다. 저장소 안의 로컬 스킬 심링크는 두지 않는다. Windows Git의 기본값 `core.symlinks=false`에서 경로 문자열 파일로 바뀌기 때문이다 |
| 본문 보존 | `SKILL.md`의 frontmatter 아래 본문은 이동 전과 같고 영문 308단어다. frontmatter에 `argument-hint`와 `disable-model-invocation: true`를 추가했다 |
| 매니페스트 | Claude Code 2.1.287의 `claude plugin validate`가 마켓플레이스와 플러그인 매니페스트를 모두 통과시켰다 |
| Claude Code 설치 | 별도 설정 디렉터리에서 마켓플레이스 등록과 설치에 성공했다. 구성은 스킬 1개, hooks·MCP·에이전트 0개다 |
| Claude Code 호출 | 모델은 사용 가능한 스킬 목록에서 `kar-plain`을 보지 못했다. `/kar-plain:kar-plain 글: …`로 호출하면 한국어 글을 만들었다. CRLF로 저장한 `SKILL.md` 그대로 확인했다 |
| 호출 정책 | `render_readme.py`가 Claude의 `disable-model-invocation: true`와 Codex의 `allow_implicit_invocation: false`가 함께 바뀌었는지 검사한다 |
| README | 두 README의 상대 링크 각 33개와 이미지 각 10개가 검사를 통과했다. 링크는 파일 이름의 대소문자까지 비교한다. Windows와 macOS는 대소문자가 달라도 파일을 찾지만 GitHub와 Linux는 찾지 못한다 |
| 줄바꿈 | 미리보기 HTML은 운영체제와 관계없이 CRLF로 쓴다. 기존 텍스트 파일의 줄바꿈은 바꾸지 않았다 |
| 보존 자료 | `outputs/**`와 이 문서의 기존 절은 바꾸지 않았다 |

확인하지 않은 것: Codex에서 플러그인을 설치하고 `$kar-plain:kar-plain`으로 호출하는 시험은 하지 않았다. Codex 문서는 `.claude-plugin/marketplace.json`과 Claude 형식 매니페스트를 읽는다고 안내하지만, README는 이 경로를 미검증으로 표시하고 Codex에는 수동 설치를 권장한다. macOS와 Linux 실기기 시험은 하지 않았다. 다만 저장소의 파일 바이트와 Claude Code의 파서는 운영체제와 관계없이 같다.

플러그인을 고쳐 배포할 때는 `plugins/kar-plain/.claude-plugin/plugin.json`의 `version`을 올린다. 버전이 같으면 Claude Code는 업데이트를 받지 않는다.
