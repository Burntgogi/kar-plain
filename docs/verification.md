# 확인한 범위

2026년 10월 5일 제작한 예시와 README를 확인했다. 원자료와 결과물은 같은 Codex 에이전트가 작성·검토했다.

| 대상 | 확인 내용 |
| --- | --- |
| 스킬 | 구조 검사 통과, 설치본과 작업본의 파일 해시 일치, 실행 본문 영어 287단어, 명시적 호출 설정 |
| 글 | 요청한 설명 목적과 스킬 지침 대조, 조건·부정·의무와 가능성의 차이 검토 |
| 도해 | SVG XML 파싱, 관계·방향과 레이블 검토, 렌더링 확인 |
| 웹 | 네 모드 전환, 주제 입력, 빈 입력 처리, 데스크톱·모바일 화면, 영상 재생과 다운로드 링크 확인 |
| 영상 | H.264, 1280×720, 24fps, 1,440프레임, 60초; 전체 디코딩·브라우저 재생과 장면별 화면 확인 |
| README | 두 언어의 내용·수치·조건 대조, 상대 링크·이미지·목차 검사, 로컬과 GitHub의 데스크톱·모바일 렌더링 확인 |
| 개인정보 | 공개 대상 29개 파일과 배포 ZIP 2개 검사; 개인 로컬 경로·연락처·인증정보가 발견되지 않았으며 이미지·영상 화면과 메타데이터 확인 |
| 라이선스 | [MIT 원문](https://opensource.org/license/mit)에 따라 LICENSE 작성, 공개 계정명으로 저작권자 표기, 한·영 README와 두 ZIP에 반영 |

영상에는 한국어 자막이 화면에 표시되며 별도 UTF-8 SRT도 제공한다. 음성 나레이션은 없다. README의 GIF는 MP4의 18초부터 36초까지를 추출한 18초 미리보기다.

이 검토는 위 제작 사례의 구조, 표시와 동작을 확인한 기록이다. 독립 인간 평가, 주제별 설명 품질 비교나 전체 환경 호환성 시험은 수행하지 않았다. README는 로컬과 비공개 GitHub 저장소에서 확인했다.

README별로 저장소 내부 링크 30개와 이미지 10개를 검사했다. 모든 상대 링크와 목차 대상이 존재했고, 두 언어판의 이미지가 브라우저에서 모두 로드됐다. 언어 전환과 예시 목차 이동을 실제로 실행했다. 390×844 화면에서 두 언어판 모두 페이지 전체의 가로 넘침이 없었다. 긴 호출문과 표는 해당 영역 안에서 가로 스크롤할 수 있다. GIF는 720×405, 108프레임, 18초다.

개인정보 점검은 README, 스킬, 예시, 문서, 공개 스크립트와 두 ZIP을 대상으로 했다. HTML에 포함된 자료도 검사한 원본과 일치한다. 로컬 작업 경로가 있는 `work/` 폴더는 공개 대상과 ZIP에서 제외했다. 점검 기록은 패턴 검색과 내용·화면 검토에 근거한다.

2026년 10월 5일 [비공개 저장소](https://github.com/Burntgogi/kar-plain)에 게시하고 Chrome에서 한·영 README를 확인했다. 두 언어판의 배너·배지·도해·웹 화면·GIF가 로드됐고, 언어 전환과 목차 이동, 예시 파일 링크를 확인했다. 390×844 화면에서 페이지 전체의 가로 넘침이 없었으며, 한국어 제목의 줄바꿈을 조정했다. GitHub의 MP4 파일 화면은 원본 다운로드 링크를 제공한다. 커밋은 GitHub 비공개 이메일을 사용하며, 로컬 작업 파일과 인증정보를 업로드하지 않았다.
